# OP7T-Kernel

Development workspace for a Kali NetHunter-capable kernel for the **OnePlus 7T Pro (`hotdog`)** on **crDroid 13 / Android 17**.

**Status:** experimental, source and build pipeline only. No validated flashable boot image is provided. Kernel source remains upstream and is fetched at a pinned commit. Development takes place in a feature branch; see its README and pull request for detailed instructions.

Upstream: https://github.com/crdroidandroid/android_kernel_oneplus_sm8150/tree/17.0

> Do not use on `hotdogg` or any other device. Back up the exact installed ROM's boot partitions and vendor modules before experimenting.
