## New bounded metadata audit

`config/wlan-rom-reference-release.json` records the separately observed reference OTA WLAN release with an explicit **reference-only** provenance statement, cross-checked with `config/rom-reference.json`. It is **not** a user-device attestation.

Download the existing CI metadata ZIP from run 40154311077 and run:

```sh
python3 scripts/audit-wlan-reference-release.py \
  --ci-metadata-zip /path/to/hotdog-wlan-rom-source-compile-40154311077.zip

# Require zero compatibility blockers (expected to exit 4 today).
python3 scripts/audit-wlan-reference-release.py \
  --ci-metadata-zip /path/to/hotdog-wlan-rom-source-compile-40154311077.zip \
  --strict
```

The script requires an eight-file bounded ZIP with no extra files, symlinks, duplicate entries, paths, kernel binaries or raw modules. It correlates the exact source SHA, build profile, sign/strip metadata, module hash, kernel release, ICNSS patch and source-parity report, 394 reported symbol CRC matches and all no-flash flags. Unexpected or altered metadata fails closed. It emits only the reference release gap and outstanding proof obligations; success of **analysis** cannot mean a release approval. The `--strict` mode returns nonzero while any release blocker or unknown remains.

Existing offline tools are `scripts/audit-module-abi.py` and `scripts/compare-rom-modules.py`. Leave their results as proof of individual comparisons only.
